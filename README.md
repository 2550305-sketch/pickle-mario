# 피클 마리오 — 점프 대모험

브라우저에서 바로 즐기는 HTML5 점프 게임입니다. 별도 설치나 파일 없이 링크만 열면 플레이할 수 있습니다.

**플레이:** https://raw.githack.com/2550305-sketch/pickle-mario/main/index.html

**피클 파티 (보드 & 미니게임):** https://raw.githack.com/2550305-sketch/pickle-mario/main/party/index.html

> 처음 열 때 raw.githack 안내 화면이 뜨면 **Open the page**를 한 번 누르면 바로 시작됩니다.

- 아이폰 Safari 지원 (화면 터치 패드 조작)
- 모든 그래픽과 사운드를 코드로 직접 그려서 외부 파일 없이 동작
- 파일 하나(`index.html`)로 이루어진 정적 페이지
